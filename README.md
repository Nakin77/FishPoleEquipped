# FishPoleEquipped

Shows an icon (and an optional text) while a fishing pole is equipped.

- Move it in Edit Mode.
- Options in *Esc → Options → AddOns → FishPoleEquipped*: icon size, show/hide icon, show/hide text, text size, text color, custom text, reset.
- The default text follows your game language.

## Releasing

Push a version tag (for example `v1.0.1`). The GitHub workflow packages the addon with the BigWigs packager and uploads it to CurseForge (needs the `CF_API_KEY` secret and the `CURSEFORGE_PROJECT_ID` variable on the repository).
